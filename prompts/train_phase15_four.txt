th_supermimic에서 source phase 일반화 실험을 실행해줘.

목적:
기존 0.5초 간격 전이 bank에서 매 세 번째 phase(1.5초 간격)만 학습하고,
학습 anchor 사이의 0.5초/1.0초 중간 전이를 추가 학습 없이 추종할 수 있는지 확인한다.
이는 reference의 frame rate를 낮추는 실험이 아니다. 모든 reference는 50Hz를 유지한다.

실행:
- 적용되는 AGENTS.md가 있으면 읽고 기존 학습 환경과 assets/data를 확인한다.
- 기존 실행 구성처럼 all, boxing, traffic_control1, traffic_control2 네 run을 GPU 0/1/2/3에서 동시에 실행한다.
- scripts/train_phase15_four.sh를 사용한다. 먼저 DRY_RUN=1로 네 명령을 확인한다.
- 비교 실험이면 MODE=both: sparse 네 run을 끝낸 뒤 같은 설정의 dense 네 run을 같은 GPU에서 실행한다.
  MODE=sparse는 sparse 네 run만 실행한다. 동시 실행 개수는 항상 네 개다.
- PYTHON은 기존 env_kimodo_inb의 실행 파일을 사용한다. 필요 없이 PyTorch/CUDA/시뮬레이터를 업그레이드하지 않는다.
- 기본 설정: 256 env, 3,000 iterations, WM-only 500회, horizon 32,
  WM/critic LR 2e-4, actor LR 5e-5(policy_lr_scale=0.25), critic_upper_bound=true,
  공통 action limit 20, compile off, seed 0, 200회마다 학습 subset 전체 평가.
  이는 안정화를 위한 시작 설정이며 Boxing의 from-scratch 장기 안정성이 입증된 설정은 아니다.
- policy, WM, critic 모두 새로 초기화한다. 기존 dense/통합/recovery checkpoint에서 warm-start하지 않는다.
- OUTPUT_ROOT는 새 경로로 지정한다. 기존 runs, 원본 CSV, assets, checkpoint를 덮어쓰지 않는다.

분할:
- tools/split_transition_phases.py가 OUTPUT_ROOT/data 아래에 매번 새 split을 만든다.
- 각 source의 끝을 cutback=0으로 잡고 매 1.5초 cutback만 학습한다. 원본 primitive는 유지한다.
- interpolation은 두 학습 anchor 사이에 있는 미학습 phase다.
- extrapolation은 학습 phase 범위 바깥이다. 두 지표를 합쳐서 일반화 성능으로 보고하지 않는다.
- 통합 run에서도 scenario namespace를 유지하여 Traffic V1/V2의 같은 action 이름이 섞이지 않게 한다.
- 원본 primitive를 학습하므로 source 자세 자체가 완전히 미학습 상태라는 주장은 하지 않는다.

평가:
- 학습 중 checkpoint 선택은 학습 subset의 실패 수와 return만 사용한다.
- 학습 종료 뒤 best_coverage.pt와 last.pt 각각을 interpolation/extrapolation에서 평가한다.
- sparse 평가에서는 --expect-heldout으로 학습 clip 누출을 검사한다.
- dense baseline은 같은 평가 clip을 학습 때 본 대조군이다. seen_training_clips를 결과에 남긴다.
- heldout 점수를 보고 재학습하거나 최적 checkpoint를 고르지 않는다.
- 최종 results.csv/results.json, run별 train_log.csv, evals 및 heldout/* 결과를 확인한다.
- sparse와 dense의 동일 group·checkpoint 규칙·subset을 비교하여 return과 실패 수를 보고한다.
- 처음은 seed 0 pilot이며 일반화 결론에는 추가 seed가 필요하다.
- 기존 Boxing reference의 target 경계 불일치 문제는 이번 실험에서 아직 수정하지 않았음을 명시한다.

명령 예시(기존 학습 컨테이너 안, repository 루트):
PYTHON=/root/anaconda3/envs/env_kimodo_inb/bin/python DRY_RUN=1 MODE=both bash scripts/train_phase15_four.sh
PYTHON=/root/anaconda3/envs/env_kimodo_inb/bin/python GPU_IDS="0 1 2 3" MODE=both OUTPUT_ROOT=runs/phase15_vs_dense_seed0 bash scripts/train_phase15_four.sh

학습이 끝나면 실제 결과를 바탕으로 요약해줘. 이번 요청은 학습과 평가이며 git push나 웹 서버 교체는 하지 않는다.
