# 동작 흐름으로 다시 판단한 결과

완주·추종·jerk와 별도로 대표 두 조건의 reference와 실제 동작 순서를 재검토했다. 전체 54조건의 자연스러움을 판정한 결과는 아니다.

## 비교 자료

각 영상은 **왼쪽 브리지 reference / 가운데 브리지 실제 / 오른쪽 direct-cut 실제**다. 기존 실제 연속 자세를 ghost 없이 25fps로 재렌더했다. 명령 전 1초~후 3.5초를 보여준다. 브리지의 B 진입은 명령 후 1.54초이므로 같은 화면 시각에 direct-cut과 B phase는 다르다.

## 관찰과 해석

**Boxing은 전환 전부터 reference와 실제 팔 자세가 다르다.** +0.6초 reference는 팔을 펼치지만 실제는 한 팔을 머리 근처에 유지한다. +1.0~1.4초에도 서로 다른 중간 자세를 거치고 +2.4초 이후 목표 자세에 가까워진다. 따라서 이 예시는 “브리지를 그대로 자연스럽게 수행”했다기보다 “다른 중간 동작을 거쳐 목표에 도달”했다고 판단한다. base tracking, reference 경계, bridge 추종 문제를 분리해야 한다.

Boxing bridge reference 자체도 팔을 펼치고 내린 뒤 B의 팔을 펼치는 자세로 들어간다. 이 순서가 필요한 준비 동작인지 불필요한 우회인지가 자연스러움의 질문이다. B의 초기 동작 때문일 수 있으므로 팔 내리기 자체를 오류로 단정하지 않는다.

**Traffic@5초는 reference부터 움직임이 줄어든다.** +0.5~1.0초 reference 관절 RMS 속도 평균은 0.078rad/s, 전환 직전 1초는 0.804rad/s다. 해당 구간 pose span RMS는 0.035rad다. 실제 로봇도 비슷하게 따라간다. 이 정체는 policy만의 문제로 보기는 어렵다. 필요한 연결인지 불필요한 대기인지는 속도 수치만으로 판단하지 않는다.

따라서 jerk 감소를 자연스러움 개선으로 등치하지 않는다. 생성 reference의 동작 순서·리듬, 실제 로봇의 재현 여부를 따로 판단한다. 현재 WM reward 예측은 자연스러움의 평가가 아니다.

## 다음 비교 제안 — 아직 수행하지 않음

같은 A 시점과 B 진입점을 유지하고 bridge 길이만 바꾸어 정체/우회가 줄어드는지 본다. 별도로 B 진입 phase를 바꾸면 준비 자세를 재차 거치는 현상이 줄어드는지도 비교한다. reference가 납득되는 연결을 보인 뒤 실제 로봇만 놓치는 조건을 추가 학습 대상으로 삼는다.

카메라가 root를 따라가므로 영상만으로 발 미끄러짐·접촉·체중 이동을 확정하지 않는다. 속도 그래프는 raw 관절각의 50Hz 차분으로 계산했으며, 흐름을 보기 위해 전환과 handoff의 ±0.04초를 그래프에서 제외했다. 원본 기록은 그대로 보존했다. 자연스러움 점수나 안전 기준은 아니다.
